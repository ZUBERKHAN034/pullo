Alerts

Know the moment something changes.

When CI finishes, someone approves or asks for changes, or you're asked to review, the notch drops down to tell you. Then it gets out of the way.

Actions

Keep an eye on your runs.

See what's running, what's waiting for approval and what just failed, across every repository you work on. Your deploys are one click away.

Run details

Every job, every step.

Open a run to follow each step live. Re-run what failed, cancel what's stuck, or jump straight to the log on GitHub.

Made to fit how you work.

Your own tabs

Write them like a GitHub search: repo:acme/api label:bug. Make tabs for runs too, like production deploys.

All your accounts

Work and personal, side by side in the same list, each with its avatar.

Liquid Glass

Glass that follows your Mac, or a solid panel if you prefer.

Keyboard first

⌥ ⌘ P from any app, then arrows, Return and ⌘ F for everything else.

Up and running in a minute.

  1. 1
    Download Pullo and drag it to Applications.
  2. 2
    Log in with the GitHub CLIbrew install gh && gh auth login
  3. 3
    Hover over the notch. That's it.

Private by design.

Pullo talks to the GitHub API straight from your Mac. It borrows the token from gh when it needs it and never stores it. There's no sign-up, and it only changes something on GitHub when you ask, like re-running a job.
